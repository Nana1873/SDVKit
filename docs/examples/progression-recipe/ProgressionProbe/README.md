# Progression Probe

This original disposable recipe target belongs to [the progression guide](../../../progression-authoring.md).
Copy only the four source/project/manifest/config files to an ignored lab source
directory, then use the existing SDVKit check/build/package workflow. It requires
the exact owned single-player fixture and never targets normal saves or Mods.

Preparation and the objective callback are synthetic. Native mailbox and quest
methods handle their respective effects, which must be observed separately through
fresh CLI/MCP reads and actual process reloads. The default 750-point condition
deliberately fails for the prepared 500 points; correcting config to 500 requires
the existing explicit config reconciliation and verified export/restaging.
